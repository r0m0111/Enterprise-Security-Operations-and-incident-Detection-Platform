# Incident 001 — Containment and Remediation

## Immediate Containment

Potential containment actions include:

1. Isolate the affected host if compromise is suspected.
2. Disable or lock the affected account if unauthorized access
   is confirmed.
3. Restrict the suspicious source IP where appropriate.
4. Preserve relevant logs and forensic evidence.
5. Increase monitoring for related activity.

## Important

No destructive remediation was performed during the lab.
The environment was intentionally preserved for analysis.
