# Python Security Analytics

## Purpose

Python was used to analyze security telemetry
generated by the Wazuh monitoring environment.

## Components

- log_analyzer.py
- ssh_analyzer.py
- web_analyzer.py
- risk_score.py

## Analytics

The project analyzes:

- SSH authentication failures
- SSH brute-force activity
- Suspicious web requests
- HTTP errors
- Source IP risk

## Risk Scoring

Events are assigned weighted scores based
on their security significance.

## Testing

Testing was performed using sanitized,
controlled security events.
