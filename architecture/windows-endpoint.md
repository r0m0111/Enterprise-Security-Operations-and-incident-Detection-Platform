# Windows Endpoint

## Role

The Windows host represents an enterprise employee workstation.

## Configuration

- OS: Windows 10/11
- Wazuh Agent: Installed
- Wazuh Manager: Configured

## Telemetry

The endpoint is configured to provide security-relevant
Windows telemetry to the centralized Wazuh platform.

## Verification

The Windows endpoint appears as an active agent in Wazuh.
